# The Evening Grove – Interactive VR Experience

The Evening Grove is a calm, immersive VR environment designed as a relaxing, non-intrusive interactive space.
Rather than focusing on traditional gameplay mechanics, the project emphasizes subtle interaction, environmental responsiveness, and atmosphere.
It focuses to be a minimal stakes; yet thoughtful, soothing and immersive experience of an evening time

---

## Overview

The experience is centered around a small, contained natural setting where the user can interact with select elements.
Each interaction is designed to be intuitive and minimal, allowing the environment itself to guide the user without explicit UI.
The player has to visit each element naturally as interact with it, making it a self contained, interactive experiences with relatively low stakes.

---

## Features

* Interactive tree responding to proximity and touch using particle effects and dynamic lighting
* Grabbable lantern with a custom shader (fresnel and pulsing emission using ShaderGraph) and particle system
* Volume control implemented through two interactive flowers 
* Proximity-based feedback to indicate interactivity
* Ambient environment design using fog, lighting, and composition to create a nature-like space

---

## Controls

* Movement via XR Device Simulator or VR controls
* Touch to trigger the energy interaction, as well as drum beats
* Grab and move the lantern as well as guitar using the controller
* Interact with flowers to adjust global audio volume

---

## Technologies Used

* Unity (XR Interaction Toolkit)
* C#
* Shader Graph
* Unity Particle Systems
* Audio Sources

## Design Approach

This project focuses on creating a responsive environment rather than a goal-oriented game.
Interactions are designed to be subtle and layered, allowing the user to explore and discover feedback naturally.

---

## Future Work

* Additional environmental motion (e.g., wind simulation, background changes)
* Expanded interaction set (visual based feedbacks)
